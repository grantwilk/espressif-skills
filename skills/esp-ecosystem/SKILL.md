# Espressif Software Ecosystem

Most frameworks build on ESP-IDF, so `esp-idf-activate-env`, `esp-idf-build`, and the device skills still apply. Use each project's own docs for specifics.

**Tools (covered by skills here)**
- esptool, espefuse, espsecure: https://github.com/espressif/esptool
- OpenOCD for Espressif chips: https://github.com/espressif/openocd-esp32
- ESP-IDF Installation Manager (EIM): https://github.com/espressif/idf-im-ui
- IDF Component Manager / registry: https://github.com/espressif/idf-component-manager, https://components.espressif.com
- IDF Monitor: https://github.com/espressif/esp-idf-monitor; size tool: https://github.com/espressif/esp-idf-size
- CI action: https://github.com/espressif/esp-idf-ci-action; Docker image `espressif/idf` (`esp-idf-ci`)

**Editors**
- VS Code extension: https://github.com/espressif/vscode-esp-idf-extension
- Eclipse plugin: https://github.com/espressif/idf-eclipse-plugin

**Frameworks and products**
- ESP-Matter (Matter smart-home SDK): https://github.com/espressif/esp-matter
- ESP RainMaker (IoT cloud and provisioning): https://github.com/espressif/esp-rainmaker
- ESP-AT (AT-command firmware for host MCUs): https://github.com/espressif/esp-at
- ESP-Hosted (use an ESP as a Wi-Fi/BT co-processor): https://github.com/espressif/esp-hosted
- ESP-ADF (audio): https://github.com/espressif/esp-adf; ESP-DL (neural networks): https://github.com/espressif/esp-dl; ESP-WHO (vision): https://github.com/espressif/esp-who
- ESP Launchpad (browser-based flashing and demos): https://espressif.github.io/esp-launchpad/

**Core**
- ESP-IDF: https://github.com/espressif/esp-idf; docs https://docs.espressif.com/projects/esp-idf/ (`esp-idf-docs-lookup`)
